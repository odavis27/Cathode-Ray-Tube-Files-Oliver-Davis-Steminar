# Cathode-Ray-Tube-Files-Oliver-Davis-Steminar
Keep in mind, this code IS NOT part of the official assignment, and was purely for illustrative purposes as it shows how the CRT can be used to render graphics (the core functionality of the project was merely the ability to move the beam, and this code uses that beam moving functionality to render interesting graphics).

    As this code was not created as part of the official assignment, generative ai tools (claude, github copilot, etc.) were used to aid in process and save me some time and effort. 

This file contains files which were used directly on the raspberry pi to run graphics, and certain files which were not ran on the pi and were only ran in order to test the graphics (and see what they would look like prior to rendering on CRT)
